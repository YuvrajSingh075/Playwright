## ▶️ Running the Tests

Install dependencies:

```bash id="vydw3v"
npm install
```

Run all tests:

```bash id="pw6cl4"
npx playwright test
```

Run tests in headed mode:

```bash id="k1pw3z"
npx playwright test --headed
```

Run API tests:

```bash id="7x8nql"
npx playwright test tests/api
```

Open HTML report:

```bash id="qz2p3o"
npx playwright show-report
```
